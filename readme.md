# EnhancedTube

EnhancedTube is a lightweight, customizable, and ad-free YouTube client designed specifically for Android TV. It provides a clean leanback interface optimized for remote control navigation.

## Features

* **Ad-Free:** Uninterrupted video playback without advertisements.
* **Custom Themes:** Personalize the interface appearance.
* **Lightweight:** Optimized for Android TV hardware performance.
* **Customizable:** Adjustable settings for player behavior and layout.
* **Leanback UI:** Designed specifically for televisions and remote controls.

## Installation

1. Navigate to the [Releases](https://github.com/TomSyk1/EnhancedTube/releases) page.
2. Download the latest `.apk` file.
3. Sideload the APK onto your Android TV using a USB drive, the Downloader app, or ADB.
4. Open EnhancedTube from your applications menu.

## Building From Source

To build the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/TomSyk1/EnhancedTube.git
   ```
2. Open the project directory in Android Studio.
3. Build the APK via **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
